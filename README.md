# Running Minutes

An [Obsidian](https://obsidian.md) plugin that automatically prepends a timestamp to every new line you create — designed for meeting notes, journals, and any time-sensitive writing.

## How it works

- Press **Enter** to start a new line → type your first character → a timestamp is automatically inserted before it
- If you pause typing for **30 seconds or more**, the next character you type also gets a timestamp
- A **ribbon icon** (clock) lets you toggle the plugin on/off at any time
- A **command** ("Insert timestamp") is available in the command palette for manual insertion

### Timestamp format

```
[May 8, 2026  2:30 PM]
```

## Installation

### From Obsidian Community Plugins

1. Open **Settings → Community plugins**
2. Search for **Running Minutes**
3. Click **Install**, then **Enable**

### Manual

1. Download `main.js` and `manifest.json` from the [latest release](https://github.com/saintsintra/running-minutes/releases/latest)
2. Copy them into `.obsidian/plugins/running-minutes/` in your vault
3. Enable the plugin in **Settings → Community plugins**
